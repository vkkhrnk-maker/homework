# Домашка

Домашка от учителя превращается в урок: теория, тренажёр по одному вопросу, выбор ответа, говорение с таймером и отчёт учителю.
Уроки и прогресс хранятся только в браузере на устройстве.

## Установка на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран „Домой"».
- **Android:** открыть сайт в Chrome → меню ⋮ → «Установить приложение».

## Разбор урока

Вставить текст от учителя и нажать «Разобрать урок». Разбирает ИИ по ключу, который хранится только на устройстве
(меню ⋯ → «ИИ для разбора уроков»): бесплатный Gemini из Google AI Studio или Claude (Sonnet) с ключом Anthropic.
В версии на claude.ai разбирает встроенный Claude, ключ не нужен.

## Материал из файла

В режиме «Текст от учителя» можно прикрепить PNG, JPG, WebP или PDF кнопкой внутри поля ввода. На компьютере работают перетаскивание файлов в поле и вставка скриншота из буфера. Ограничение одной подборки — до пяти изображений либо один PDF, суммарно до 10 МБ; PDF — до десяти страниц, изображения — до 8000 px по каждой стороне.

1. Прикрепить материал и нажать «Распознать текст».
2. Проверить и при необходимости отредактировать результат в том же поле. Уже введённые заметки сохраняются; распознанный текст добавляется после них в порядке файлов и страниц. Пропуски упражнений остаются пропусками, нечитаемые места помечаются.
3. Нажать «Разобрать урок». Само распознавание урок не создаёт.

Файлы отправляются в выбранный Gemini или Claude только по нажатию кнопки распознавания. Если настроен ключ запасного сервиса, он может использоваться при временной недоступности основного; оба назначения показаны рядом с вложениями. Для файлов нужен собственный API-ключ на устройстве, даже если обычный текст разбирает встроенный Claude. Бинарные файлы находятся только в памяти вкладки и не записываются в localStorage, базу уроков или синхронизацию. При отмене и временной ошибке прикреплённые файлы и введённый текст остаются; после успешного создания урока черновик очищается. Удаление вложения не стирает уже добавленный текст.

Структуру PDF, число страниц и защиту паролем проверяет локально выполняемый [PDF.js](https://mozilla.github.io/pdf.js/) 6.5.438 (Apache-2.0), который загружается по необходимости с jsDelivr. Сам PDF при этой проверке никуда не отправляется. Распознавание использует native image/document inputs существующих Gemini/Claude API, отдельного OCR-сервиса нет.

Проверки логики: `node --test tests/file-intake.test.cjs`. Они покрывают ограничения, сохранение черновика, отмену, повтор после ошибки, порядок страниц и media payloads/retry/fallback без настоящих API-запросов.

## Обновление

1. Правки в `src/homework.html` (этот же файл публикуется на claude.ai).
2. `python3 build.py`: соберёт `index.html`, `soft.html`, `blue.html`, `fromt.html` и обновит версию кэша в `sw.js`.
3. Закоммитить и запушить: GitHub Pages обновится сам.

## Варианты оформления

- `index.html` — основная голубовато-сиреневая версия Fromt с белыми карточками и компактными контролами
- `soft.html` — прежняя светлая версия с чёрными карточками и пастельным фоном
- `blue.html` — голубая обложка и персиковые акценты для сравнения
- `fromt.html` — холодный голубовато-сиреневый градиент, белые карточки и компактные контролы по мотивам [fromt.app](https://fromt.app/)

Все варианты используют `src/homework.html`. Светлое оформление находится в `src/soft-theme.css`, вариант Fromt — в `src/fromt-theme.css`.

В основной версии у пяти встроенных уроков есть тематические иллюстрации в `illustrations/`. Это сохранённые PNG с приглушёнными голубыми заливками, созданные встроенным imagegen; промпты и референсы перечислены в `illustrations/prompts-v4.json` (предыдущие версии сохранены рядом). Для новых пользовательских уроков автоматическая генерация картинок пока не подключена. На карточках показан общий прогресс по выполненным заданиям и текущий этап; открытие теории не увеличивает процент. Нажатие на карточку всегда открывает теорию.

Для просмотра открывайте опубликованный сайт или собранный `index.html`. Открытие `src/homework.html` переводит на `index.html`, чтобы исходник без обёртки сборки не показывал скрытые окна и неверную кодировку.
